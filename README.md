# SkyPulse

SkyPulse is a modern weather forecasting web application built using Spring Boot, HTML, CSS, and JavaScript.  
It provides real-time weather updates with a premium glassmorphism UI and dynamic weather-based themes.

---

## Features

- Real-time weather data
- City-based weather search
- Dynamic weather themes
- Responsive UI
- Glassmorphism design
- Smart weather messages
- Humidity tracking
- Weather condition icons
- Feels-like temperature
- Visibility details
- Forecast section UI

---

## Installation

### Clone Repository

```bash
git clone https://github.com/K-Kathiresan/SkyPulse.git
```

### Run Project

```bash
mvn spring-boot:run
```

### Open Browser

```bash
http://localhost:8080
```
